# Ayoub Heart — لاندنج بيدج عربي / إنجليزي

صفحة ثابتة (HTML + CSS + JS) — مفيش سيرفر ولا قاعدة بيانات، تترفع على أي هوست.

## الملفات

```
index.html              ← الصفحة (لازم تكون في جذر الهوست public_html مباشرة)
robots.txt
assets/
  css/style.css         ← التصميم والألوان (قسم :root أول الملف)
  js/i18n.js            ← كل النصوص بالعربي والإنجليزي
  js/main.js            ← بيانات العيادة (CONFIG أول الملف) + الفورم + مبدّل اللغة
  img/                  ← اللوجو، الأيقونة، صورة الطبيب، صورة المشاركة
```

## قبل الرفع — عدّل دول

1. **`assets/js/main.js` ← `CONFIG`**: رقم واتساب (بالصيغة الدولية بدون + : 201012345678)، رقم التليفون، الإيميل، رابط الخريطة، فيسبوك وإنستجرام.
2. **`assets/js/i18n.js`**: اسم الدكتور، المؤهلات، العنوان، المواعيد، الأرقام (+15 سنة، +10,000 مريض، 4.9). **أي نص تغيّره، غيّره في `ar` و `en` بنفس المفتاح.**
3. **`assets/img/doctor.jpg`**: صورة الدكتور. لتغييرها ارفع صورة جديدة بنفس الاسم.

> ملحوظة: النص العربي موجود كمان جوه `index.html` (للسيو ولو الجافاسكريبت مشتغلش). لو عدّلت نص عربي في `i18n.js` عدّله في `index.html` كمان، أو سيبه — الموقع هيعرض نسخة `i18n.js` على طول.

## الرفع على الهوست (cPanel / Hostinger)

1. File Manager ← `public_html`
2. Upload ← ارفع ملف الـ zip ← Extract
3. اتأكد إن `index.html` جوه `public_html` مباشرة (مش جوه فولدر فرعي).
4. افتح الدومين — المفروض يفتح بالعربي.

## اللغة

- العربي هو الافتراضي. الزائر لما يختار English بيتحفظ اختياره.
- رابط مباشر للإنجليزي: `https://your-domain.com/?lang=en` (ينفع في إعلانات بالإنجليزي).
- كل اللي بيتغير: النصوص، الاتجاه RTL/LTR، الخط، العنوان، الـ meta description، رسائل الخطأ، رسالة واتساب، لغة الخريطة.

## الفورم

بيتحقق من البيانات وبعدين يفتح واتساب برسالة جاهزة فيها بيانات المريض (باللغة اللي الزائر مختارها).
لو عندك Google Tag Manager أو Meta Pixel على الصفحة، الفورم بيبعت حدث `booking_submit` و `Lead` تلقائيًا.
